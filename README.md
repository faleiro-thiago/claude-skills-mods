# claude-skills-mods
Facilitadores pessoais para Claude Code. Cada item tem versão própria (`VERSION` + `CHANGELOG.md`) e tag `item/vX.Y.Z`.

| Item | Tipo | Versão |
|---|---|---|
| clean-view | mod próprio | ver `clean-view/VERSION` |
| statusbar | cópia modificada (MIT) | ver `statusbar/VERSION` |
| skins, filetree, image-view | referência fixada a plugins públicos | ver `plugins/*/VERSION` |

Instalar: `./install.sh`. Alterar e versionar: `scripts/bump.sh <item> patch|minor|major "mensagem"`.
